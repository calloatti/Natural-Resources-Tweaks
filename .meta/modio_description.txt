<p>Does it bother you that placing a single carrot or a massive oak tree creates a giant, screen-blocking &quot;ghost&quot; of a fully grown plant? This mod fixes the planting preview to be more realistic by replacing the oversized mature preview models for <strong>Trees, Crops, and Bushes</strong> with their <strong>Seedling</strong> variants.</p>
<h3 id="features">Features</h3>
<p>Area selection modifiers for Mark/Unmark tree cutting area
There is now a button to cycle area selection options
Tree cutting area selector includes verticality, not restrained to selecting tiles on the same height
By selecting whole map option, and only dead trees option, you can mark all dead trees in the map for cutting.</p>
<h3 id="planting-treescrops">Planting trees/crops</h3>
<p>There is now a button to cycle area selection options
In place crop/tree replanting. To change an existing crop/tree, just replant a new crop/tree over it
Alt: Skips marking for demolition when replanting. Set MarkForDemolition=False in the config file to always skip demolition.
Allows beehives to be placed over crops.
Basic Forest planter tool
Shows Foresters/Farms range when planting trees/crops</p>
